Features

Quick Start

五步完成定制镜像

以管理员身份运行，按「操作引导」即可，所有路径会自动创建并记忆。

解包 / 挂载

解包 ISO 或直接选择 install.wim，挂载到空的工作目录。

深度定制

集成驱动与补丁、预装应用、精简组件、品牌与界面定制。

配置应答

可视化填写无人值守选项，实时预览并保存 autounattend.xml。

卸载提交

回到挂载管理，卸载并提交更改，改动写回 WIM。

生成成品

一键生成 ISO、制作启动 U 盘，或经 PXE 批量部署。

系统要求

● 操作系统

Windows 10 / Windows 11（64 位）；可定制的映像同样支持 Win10 / Win11 各版本。

● 权限与运行

需管理员权限运行；安装版/便携版需系统内置 WebView2，缺失时请用在线或离线版。

● 磁盘空间

建议预留 15 GB 以上工作空间（挂载、补丁与临时文件），离线版成品体积较大。
